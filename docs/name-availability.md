# Name Availability Check: "Moral Circle AI"

Check date: 2026-10-23. Scope: the name recommended in Stage 2 of the
planning package. This is a desk check, not legal advice or a formal
clearance opinion.

## Trademark registers

| Source | Query | Result |
|---|---|---|
| TMview (EUIPO network: EUIPO, USPTO, national offices) | word mark contains `moral circle` | no record |
| TMview, control query | word mark contains `circle ai` | many hits, so the search works; closest: `CIRCLE AI` (USPTO 99892238, CircleCo, Inc., filed 2026-06-18) |

`CIRCLE AI` shares the words "circle" and "AI" but not the distinctive
element "moral". It is noted here as the nearest existing mark.

## GitHub

The user or organization names `moral-circle-ai`, `moralcircleai` and
`moralcircle` do not exist. The repository stays at
`flow-84/sentient-centered-ai`, because it is bound to the project.

## Conclusion

No registered trademark blocks the name. The short domains `moralcircle.*`
are taken, so `moralcircleai.org` / `moralcircleai.com` are the realistic
domain options. Registering a domain or filing a trademark costs money and
is a maintainer decision, not part of this repository.
